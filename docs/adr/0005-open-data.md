# ADR 0005: 事業所データは WAM NET のオープンデータを使い、職員が入力する項目と分ける

- 状態: 採用
- 日付: 2026-10-25

## 背景

架空のデータでは、検索の手触り（件数、表記ゆれ、欠けている項目）を確かめられない。障害福祉サービス等情報公表システム（独立行政法人福祉医療機構 WAM NET）は、事業所情報をサービス種別ごとの CSV で公開している。

- 公開ページ: https://www.wam.go.jp/content/wamnet/pcpub/top/sfkopendata/
- 形式: サービス種別ごとの全国 1 ファイル（ZIP 入り CSV、UTF-8 BOM 付き、CRLF）。放課後等デイサービスはコード 65、児童発達支援は 63
- 時点: 毎年 3 月末・9 月末（取り込んだのは 2026 年 3 月末時点）
- 利用条件: 公共データ利用規約（第1.0版）（PDL1.0）。出典の記載が必要で、加工した場合はその旨を示す

## 決定

- rake タスク（`bin/rails open_data:import`）で ZIP を取得・展開し、指定した都道府県（既定は北海道・大阪府）だけを upsert する。データファイルはリポジトリに入れない
- テストには、同じ列構成で作った架空の CSV（`spec/fixtures/files/wamnet/`）だけを使う
- 一意キーは「サービス種別コード:NO」。事業所番号は重複がある（同じ番号で別名の行がある）ので使わない
- 先頭列はドキュメント上「市町村コード」だが、実データは指定権者（道府県・政令市）のコードなので使わず、住所の「市区町村」欄から都道府県と市区町村を分ける
- 紹介文・送迎の有無・支援内容はオープンデータに含まれないので、事業所の職員が管理画面で入力する。再取り込みではこれらの列を上書きしない
- 画面のフッター・詳細ページ・「データと利用条件」ページに出典と時点を表示する
- 動作確認用の架空データには「サンプルデータ（架空）」と表示する。口コミや利用者の声は掲載しない

## 結果

- 送迎の有無はほとんどの事業所で「未登録」になる。検索の「送迎あり」は事業所が登録したものだけに当たると画面に書いている
- 利用規約のページには旧版（政府標準利用規約 第2.0版）の文言も残っているが、どちらも CC BY 4.0 と互換で、出典の記載で条件を満たせる
- 公開ページは、オープンデータを使った場合にフォームから知らせるよう求めている（条件ではなく依頼）。公開して運用するときはこれに応じる
