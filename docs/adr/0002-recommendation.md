# ADR 0002: 「似ている事業所」は内容ベースの点数で選び、理由を表示する

- 状態: 採用
- 日付: 2026-10-25

## 背景

事業所の詳細ページで、比較の候補になる事業所を出したい。立ち上げ時点では閲覧やお気に入りの履歴がほとんどなく、協調フィルタリングは使えない。また、福祉サービスの選択では「なぜ勧められたのか」が分からない推薦は信頼されにくい。

## 決定

`Recommendations::SimilarFacilities` で、基準の事業所と候補の重なりを重み付きで足し合わせる。

| 要素 | 重み | 理由の表示例 |
|---|---|---|
| 同じサービス種別 | 0.35 | 同じ放課後等デイサービス |
| 近さ（0km で 1、10km で 0） | 0.30 | 約1.2km |
| 支援内容の重なり（Jaccard 係数） | 0.20 | 共通の支援内容: 運動療育 |
| 土日祝の利用できる曜日の重なり | 0.10 | 土曜・祝日も利用できる |
| どちらも送迎あり | 0.05 | 送迎あり |

- 候補は同じ都道府県で、半径 10km を囲む緯度経度の範囲から近い順に 200 件までを読む
- サービス種別の一致を近さより重くした。放デイ（就学児）と児発（未就学児）は対象年齢が違い、近くても代わりにならないため
- 点数の内訳をそのまま理由として表示する

## 結果

- 重みは定数で、単体テストで並び順と理由を固定している。変えるときはテストの期待値も見直す
- オープンデータには支援内容と送迎がないため、実データでは主にサービス種別・距離・曜日で決まる。職員が管理画面で入力すると精度が上がる
- 履歴がたまったら、お気に入りの共起などを点数に足すことを検討する（その場合も理由を出せる形にする）
